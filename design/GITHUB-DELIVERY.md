## 独立运行

本次使用Node.js v24.15.0，在单独克隆目录安装依赖和构建，不借用原上级目录的依赖。

```powershell
npm ci
npm run dev
```

默认开发入口为 `http://127.0.0.1:5180/`。构建与生产预览：

```powershell
npm run build
npm run preview -- --port 5181
```
